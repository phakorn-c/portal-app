# เดโมเว็บแบบดูตามได้

ใช้หน้านี้ตอนนำเสนอ ส่วนคำสั่งตั้งค่า รีเซ็ตฐานข้อมูล นำเข้า OCR และกู้คืนอยู่ใน [คู่มือเทคนิค](demo-runbook.md) เดโมนี้ใช้ข้อมูลตัวอย่าง ไม่ใช่เว็บ production

| บทบาท     | เข้าเว็บ       | บัญชีตัวอย่าง                    |
| --------- | -------------- | -------------------------------- |
| ผู้เข้าชม | `/procurement` | ไม่ต้องเข้าสู่ระบบ               |
| สมาชิก    | `/login`       | `test@example.com` / `password`  |
| ผู้ดูแล   | `/login`       | `admin@example.com` / `password` |

เตรียมข้อมูลตามคู่มือเทคนิคก่อนเริ่ม แยกโปรไฟล์เบราว์เซอร์ของสมาชิกกับผู้ดูแล และใช้ประกาศที่สร้างใหม่เมื่อจะลองลบหรือแก้สิทธิ์ **อนุมัติข้อมูลที่สกัด ≠ เผยแพร่ประกาศ**

## 1. ผู้เข้าชม: หาและตรวจต้นฉบับ

1. เปิด `/procurement` ค้น `Smart Traffic` แล้วลองกรองหน่วยงาน วิธีจัดซื้อ หมวดหมู่ หรืองบประมาณ
2. เปิด **Khon Kaen Smart Traffic Upgrade**: ดูสถานะ งบ วันสิ้นสุด รายละเอียด และ PDF
3. ล้างตัวกรองแล้วดูว่ารายการกลับมา ไม่มีบัญชีก็ค้นหาและดาวน์โหลดเอกสารได้

## 2. สมาชิก: เก็บสิ่งที่สนใจ

1. เข้าระบบ ค้น `School` แล้วกด **บันทึกการค้นหานี้** ตั้งชื่อ `School opportunities` โดยเปิดแจ้งเตือนไว้
2. เปิด `/user/saved-searches` ลองค้นซ้ำและแก้ชื่อ; `/user/history` มีประวัติดูประกาศกับประวัติค้นหา
3. เปิด `/user/notifications` ดูรายการแจ้งเตือนและสวิตช์ช่องทาง จากเมนู Settings ดูโปรไฟล์ รหัสผ่าน ธีม และ 2FA (อย่าเปลี่ยนรหัสหรือเปิด 2FA บัญชีที่ใช้ร่วมกัน)

## 3. ผู้ดูแล: ตรวจแล้วค่อยเผยแพร่

1. เปิด `/admin` สร้างประกาศฉบับร่าง เช่น `School Demo Opportunity` และดูตัวกรอง/รายการประกาศ
2. เปิดหน้าตรวจผลสกัดของประกาศตัวอย่างหมายเลข 6 แก้เฉพาะข้อมูลที่มีหลักฐานแล้วกดอนุมัติ: ประกาศยังเป็น **ฉบับร่าง**
3. เผยแพร่ประกาศตัวอย่างหมายเลข 7 แยกต่างหาก กลับไปค้นจากหน้าผู้เข้าชม; เห็นข้อมูลที่อนุมัติและ PDF แต่ไม่เห็น raw text, confidence หรือ warning
4. หน้าตรวจของหมายเลข 8 เป็นความล้มเหลวจำลอง ลอง retry ได้สูงสุด 3 ครั้ง; `/admin/users` ใช้ตรวจการจัดการสิทธิ์ (เปลี่ยนกลับเมื่อสาธิตเสร็จ)

หมายเลขข้างต้นอ้างถึงข้อมูลที่ seed ใหม่เท่านั้น หากนำเข้าข้อมูล OCR ให้ใช้ ID ที่อ่านจากคำสั่งในคู่มือเทคนิค ไม่เดาหมายเลข

## 4. ปิดวงจรการแจ้งเตือน

เผยแพร่ `School Demo Opportunity` ขณะสมาชิกยังเปิดแจ้งเตือนของ `School opportunities` แล้วกลับไป `/user/notifications` ตรวจข้อความและทำเครื่องหมายว่าอ่านแล้ว

## พูดให้ตรงกับสิ่งที่ทำได้

| เส้นทาง                       | คำอธิบายที่ถูกต้อง                                    |
| ----------------------------- | ----------------------------------------------------- |
| อัปโหลด PDF ผ่านเว็บ          | ผลทดสอบที่กำหนดด้วยชื่อไฟล์ ไม่ได้อ่าน PDF ไม่ใช่ OCR |
| นำเข้าจาก `portal-ocr`        | ผล OCR ที่ประมวลไว้ล่วงหน้า รอผู้ดูแลตรวจและเผยแพร่   |
| URL `demo.invalid`            | ตัวระบุเดโม ไม่ใช่แหล่งข้อมูลทางการ                   |
| 90 แถว / ผ่าน 70 / ไม่ผ่าน 20 | ผลซ้อมวันที่ 11 ก.ย. 2569; 20 แถวติดกฎชื่อหน่วยงาน    |

ไม่กล่าวว่ามี RAG, vector search, คะแนน WER/F1 หรือระบบ deploy จริง การนำเข้าสำเร็จไม่ได้พิสูจน์ความแม่นยำ OCR

**ถ้าเดโมสะดุด:** รายการหายให้ตรวจการ seed/reset แบบมี guard ในคู่มือเทคนิค; แจ้งเตือนไม่ขึ้นให้ตรวจสวิตช์และ queue; PDF เปิดไม่ได้ให้ลอง preview ในหน้า; งานสกัดหมายเลข 8 ล้มเหลวโดยตั้งใจ
