# ตอนนี้เว็บทำอะไรได้บ้าง

| เรื่อง                                                  | สถานะ                                                                                        |
| ------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| ผู้เข้าชมค้นหา กรอง ดูประกาศที่เผยแพร่และ PDF           | ใช้ได้                                                                                       |
| สมาชิกลงทะเบียน บันทึกการค้นหา ดูประวัติและการแจ้งเตือน | ใช้ได้                                                                                       |
| ผู้ดูแลจัดการประกาศ ผู้ใช้ สิทธิ์ และอนุมัติผลสกัด      | ใช้ได้                                                                                       |
| นำเข้า JSON/PDF จาก `portal-ocr` เป็นฉบับร่าง           | ใช้ได้; ตรวจแต่ละแถวและข้าม `record_key` ซ้ำ                                                 |
| ผล OCR จากชุดข้อมูลจริง                                 | นำเข้าบางส่วน: ซ้อม 11 ก.ย. 2569 ผ่าน 70 จาก 90 แถว; อีก 20 แถวไม่ผ่าน taxonomy ชื่อหน่วยงาน |
| การอัปโหลด PDF ผ่านเว็บ                                 | ใช้ตัวสกัดผลทดสอบจากชื่อไฟล์ **ไม่ใช่ OCR**                                                  |
| แสดงที่มาบนหน้าสาธารณะ                                  | เมื่ออนุมัติและเผยแพร่แล้ว และมี URL แหล่งข้อมูลที่ใช้ได้                                    |
| 2FA                                                     | มีในระบบ แต่ไม่อยู่ในเดโมหลัก                                                                |
| ดึงข้อมูลสดระหว่างเดโม                                  | ไม่ใช้; ใช้ชุดข้อมูลที่เตรียมไว้                                                             |
| RAG/vector search และการวัด WER/F1                      | ยังไม่มี                                                                                     |

**ลำดับสำคัญ:** นำเข้า/อัปโหลด → ผู้ดูแลตรวจแก้และอนุมัติ → ผู้ดูแลเผยแพร่แยกอีกครั้ง → ผู้เข้าชมเห็นประกาศและ PDF ข้อมูลดิบจากการสกัดยังอยู่ฝั่งผู้ดูแล

ตัวเลข 70/20 เป็นผลการซ้อม ไม่ใช่ข้อรับประกันว่าการนำเข้าครั้งถัดไปจะได้เท่ากัน; `portal-ocr` ยังไม่ได้ส่ง `raw_text` และ `validation_flags` แยกมาในชุดส่งออกครั้งนั้น ดู [ภาพรวม](../README.md), [คู่มือเดโม](human-demo-runbook.md) และ [คำสั่งซ้อม](demo-runbook.md)
